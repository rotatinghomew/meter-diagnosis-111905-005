# 对照：把关闭/未覆盖时段误当“零超线”的后果

下列每条都说明错误口径会怎样改变开放决定；正确口径下这些时段保持未知或按实测计入。

## 1. K2-2（名义 closed/eq1，事实 11:00-11:12 可能开门、设备 11:08 起开）
- 错误做法：把关门标签当成零超线
- 实际资料：A_IN/B_IN/EAST 各 30/30 超线，HALL 25/30（MC 替代后）
- 被污染的决定：会虚构 A+B 闭门+设备开的合格样本，错误放行设备开启时的 A+B 闭门预约

## 2. K6-4（A+B 闭门，EAST 点位零覆盖）
- 错误做法：把未提供观测的 EAST 当成零超线
- 实际资料：EAST 覆盖 0 分钟，指标无定义；该日不能计入 P1 配对日
- 被污染的决定：会把覆盖缺口伪装成合格日，提前确认 A+B 闭门许可并掩盖试验缺口

## 3. 设备开启 block 群（K2-2,K2-3,K5-2,K5-3）
- 错误做法：用白天设备关闭的零超线基线代替晚间/同设备基线
- 实际资料：无任何 (eq=1, 无活动) 基线，增量无法估计，4 个 eq1 条件全部未知
- 被污染的决定：会把设备背景造成的超线错误记到活动/门状态头上，错误拒绝或确认单间条件

## 4. B 单间闭门（全部 8 个试验日零覆盖）
- 错误做法：把没有闭门 B 试验当成闭门零超线
- 实际资料：没有任何 block 与 B+closed 相容，状态为未知
- 被污染的决定：会凭空确认 B 闭门许可，排期时给阅读/手工组安排无法兑现的闭门时段
